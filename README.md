# IoT Sensor Dashboard

A small Internet of Things dashboard prototype that connects sensor firmware concepts with a simple web dashboard.

## Features

- Arduino sensor node example
- Node.js telemetry server
- Browser dashboard UI
- JSON sample readings

## Stack

`Arduino` · `JavaScript` · `Node.js` · `HTML` · `CSS` · `IoT`

## Run dashboard server

```bash
cd server
node index.js
```
