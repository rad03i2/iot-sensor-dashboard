# EcoPulse AI

> Virtual AI Environmental Intelligence & Digital Twin Platform

EcoPulse AI is an environmental monitoring and simulation platform that turns the original IoT Sensor Dashboard prototype into a multi-station virtual environmental intelligence system. It is designed to work **without physical sensors**, while keeping a clean path to real ESP32/Arduino hardware and Adafruit IO later.

## Why this project exists

The project demonstrates how environmental engineering, cloud IoT, real-time APIs, simulation, analytics and AI can work together in one system. The first milestone focuses on a scientifically transparent virtual monitoring network rather than pretending simulated values are real measurements.

## Milestone 1 — Foundation

- Five virtual monitoring stations with different environmental profiles
- Correlated simulation for temperature, humidity, PM2.5, PM10, CO2 and noise
- Scenario engine: baseline, traffic surge, dust storm, industrial event, heat wave
- Environmental health score and estimated air-quality indicator
- Automatic alert detection
- REST API with FastAPI
- WebSocket live stream
- Optional Adafruit IO publisher
- Responsive bilingual-ready web dashboard foundation
- Docker support
- Tests for simulation invariants
- Clear source provenance: every simulated reading is explicitly marked `simulated`

## Monitoring stations

| ID | Station | Profile |
|---|---|---|

## Quick start

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn backend.app.main:app --reload
```

Open:

- API docs: `http://127.0.0.1:8000/docs`
- Dashboard: `http://127.0.0.1:8000/`
- Health: `http://127.0.0.1:8000/health`

## Optional Adafruit IO

Copy `.env.example` to `.env` and provide your own credentials locally:

```env
ADAFRUIT_IO_ENABLED=true
ADAFRUIT_IO_USERNAME=your_username
ADAFRUIT_IO_KEY=your_private_key
```

Never commit an Adafruit IO key to GitHub.

## API snapshot

```text
GET  /health
GET  /api/stations
GET  /api/latest
GET  /api/stations/{station_id}/latest
GET  /api/alerts
GET  /api/summary
POST /api/simulation/tick
POST /api/scenarios/{scenario}
WS   /ws/environment
```

Supported scenarios: `baseline`, `traffic_surge`, `dust_storm`, `industrial_event`, `heat_wave`.

## Transparency

Milestone 1 uses synthetic environmental data generated by a correlated simulation model. These values are for software development, education and demonstration; they are **not regulatory measurements, medical advice, or a substitute for calibrated environmental instruments**.

## Roadmap

Next milestones add a time-series database, geospatial pollution maps, environmental standards profiles, advanced data-quality scoring, anomaly detection, forecasting, explainable AI, automated PDF reports, a digital-twin scenario lab, authentication, multilingual UX and real physical sensors.
